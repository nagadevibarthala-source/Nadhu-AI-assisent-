# Nadhu AI Assistant 🤖

Nadhu AI Assistant is a Python-based voice assistant that helps users perform tasks using voice commands.

## Features
- Voice command recognition
- Text-to-speech response
- Open applications using voice
- Open websites like YouTube, WhatsApp, ChatGPT
- Date and time information

## Technologies Used
- Python
- Speech Recognition
- Pyttsx3
- Webbrowser

## How to Run

1. Clone the repository

2. Install requirements

3. Run:

python main.py
